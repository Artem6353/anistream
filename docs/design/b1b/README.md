# B1-B: артефакты preview

Всё в этой папке сгенерировано локально из ветки `design/aninova-3-b1-b-hybrid-2026-11`. Это не production-скриншоты и не дизайн-макеты: снято с работающего preview.

## Состав

| Файл/папка | Что внутри |
|---|---|
| `screens/{390,768,1024,1440,1920,3840}/` | 54 снимка: 9 экранов × 6 ширин |
| `screens/states/` | 7 состояний: TV-фокус, поиск, меню, мобильная навигация, плеер |
| `screens/manifest.json` | URL, статус, ширина документа и viewport для каждого снимка |
| `audit.json` | overflow, контраст, семантика, клавиатура, reduced motion, вес ресурсов |
| `perf.json` | LCP, JS/CSS/img/total, запросы, DOM по маршрутам |

## Экраны

`home`, `catalog`, `anime`, `watch`, `comics`, `comic`, `read`, `profile`, `auth`.

## Ширины

| Папка | Viewport | Режим |
|---|---|---|
| `390` | 390×844 | мобильный, нижние вкладки |
| `768` | 768×1024 | планшет, нижние вкладки |
| `1024` | 1024×768 | планшет-ландшафт, боковые фильтры |
| `1440` | 1440×900 | десктоп |
| `1920` | 1920×1080 | TV, `?tv=1`, только viewport |
| `3840` | 3840×2160 | 4K TV, `?tv=1`, только viewport |

Для `390–1440` снимки полностраничные; фиксированные нижняя навигация и подсказка скрываются, чтобы не дублироваться в середине документа. Мобильная навигация и меню сняты отдельно в `states/`.

## Как переснять

```bash
npx next build
ANINOVA3_PREVIEW=1 npx next start -p 3521
A3_BASE=http://localhost:3521 node scripts/aninova3/screenshots.mjs
A3_BASE=http://localhost:3521 node scripts/aninova3/audit.mjs
```

Скриншоты — JPEG, quality 78. 4K-снимки тяжёлые; при необходимости quality можно снизить в `scripts/aninova3/screenshots.mjs`.

## Важно

- Только тёмная тема: светлая в B1-B не проектировалась.
- TV-состояния получены клавиатурной эмуляцией Chromium, не реальным пультом.
- Постеры каталога реальные; комиксы и их страницы — вымышленные демо-данные.
- В кинозале может не быть источника: тогда виден постер и честное пустое состояние, а не имитация видео.
