## 1. P0 — критично (безопасность, чинить немедленно)

### P0-1. RLS: любой может редактировать ЛЮБОЙ отзыв
`supabase/schema.sql:26` — `create policy reviews_update on public.reviews for update using (true)`.
Anon-ключ лежит в клиентском бандле → прямой `PATCH /rest/v1/reviews?id=…` меняет чужие тексты/рейтинги.
**Фикс:** миграция 010: `update` — только автору (`user_id = auth.uid()::text`) и service_role (RLS не ограничивает service-ключ):
```sql
drop policy if exists reviews_update on public.reviews;
create policy reviews_update on public.reviews for update
  using (user_id is not null and user_id = auth.uid()::text)
  with check (user_id is not null and user_id = auth.uid()::text);
```
**Труд:** 0.5 ч. **Приёмка:** анонимный PATCH → 404/403; наш API (service) модерации работает; UI-редактирование своего отзыва (если появится) — работает.

### P0-2. RLS: открытые write-политики review_reactions (накрутка лайков)
`003_review_reactions.sql`: insert/update/delete `with check (true)`. user_id — серверная httpOnly-cookie `ani_uid`
для нашего API, но прямой REST принимает любой user_id → бот-накрутка счётчиков.
**Фикс:** миграция 010: все write-политики реакций → `to service_role` (react-роут ходит service-ключом при заданном `SUPABASE_SERVICE_KEY`).
**Труд:** 0.5 ч. **Приёмка:** прямой anon insert в review_reactions → 403; лайк через UI сохраняется.

### P0-3. RLS: открытый insert в push_subs (спам-подписки)
`schema.sql`: `push_insert … with check (true)`. Subscribe-роут и так ходит service-ключом.
**Фикс:** миграция 010: insert → `to service_role`.
**Труд:** 0.5 ч. **Приёмка:** anon insert → 403; подписка через UI создаётся.

> Все три правки — **одна миграция `010_rls_hardening.sql` + один коммит**, код приложения не меняется.

## 2. P1 — высоко

### P1-1. Отсутствие security-заголовков (зонд прода: НЕТ ни одного)
Нет CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy.
JWT в localStorage + inline-скрипт темы => CSP нужна аккуратно.
**Фикс:** `next.config.ts` → `headers()`:
- `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`
- `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(), geolocation=()`
- CSP: `default-src 'self'; script-src 'self' 'sha256-<hash PRE_HYDRATE>' https://challenges.cloudflare.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; frame-src https://kodik.info https://kodikplayer.com https://animego.org https://aniboom.one https://www.youtube.com https://challenges.cloudflare.com; connect-src 'self' https://*.supabase.co https://graphql.anilist.co https://shikimori.io https://api.jikan.moe wss://*.supabase.co;`
  (начать неделю в режиме `Content-Security-Policy-Report-Only`, собрать нарушения, затем enforce).
**Труд:** 3 ч (с прогоном report-only). **Приёмка:** заголовки в ответе; консоль без CSP-violation на 10 ключевых страницах; Turnstile и embed-плееры работают.

### P1-2. Rate-limit не покрывает часть writable-роутов
`LIMITS` (middleware): search/providers/reviews/reco/availability. Вне лимитов: `/api/push/subscribe`, `/api/push/vapid`, `/api/social/captcha`, `/api/report`, `/api/dmca`, `/api/quiz`, `/api/social/feed`, `/api/social/taste`.
**Фикс:** добавить префиксы (10–20/мин). **Труд:** 1 ч. **Приёмка:** burst 40 POST /api/push/subscribe → 429.

### P1-3. Инфляция жанровых счётчиков ачивок
`trackEvent('watch')` инкрементит жанры на **каждый заход** на серию, а не на уникальный тайтл → «Всеядный/Романтик» накручиваются повторными просмотрами.
**Фикс:** множество учтённых slug'ов `anistream:ach_watched` (scope-aware); инкремент жанров только при первом slug. **Труд:** 1 ч.
**Приёмка:** повторный просмотр серии не меняет топ-жанров в /profile/stats и прогресс жанровых ачивок.

### P1-4. N+1 в /messages
Список тредов: 2 запроса **на тред** (messages + profile). При 50 тредах = 100 RTT.
**Фикс:** батч: `dm_messages?thread_id=in.(…)` одним запросом + `profiles?user_id=in.(…)` одним. **Труд:** 1.5 ч.
**Приёмка:** NetworkDevTools: ≤3 запроса на открытие /messages при 20 тредах.

### P1-5. Тяжёлые выборки profile_history (reco/taste/feed)
`limit=10000` строк истории всех пользователей на каждый запрос рекомендаций.
**Фикс:** limit 2000 + `Cache-Control: s-maxage=3600` на /api/reco (коллаб-часть) и /api/social/taste; в feed — limit 200 на пользователя. **Труд:** 1 ч.
**Приёмка:** p95 /api/reco < 400 мс; ответ кешируется (заголовок age).
