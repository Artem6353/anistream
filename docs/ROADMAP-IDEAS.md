## Свои идеи (вне конкурентов)

1. **P1**: Push по онгоингам из «Моего списка»: при выходе серии у тайтла из списка — персональный пуш (ежедневный workflow уже есть; добавить фильтр подписок).
2. **P2**: Экспорт/импорт списков MAL/AniList (XML/CSV) — миграция пользователей с других платформ.
3. **P2**: «Смотрю сейчас» — публичный статус в профиле (тайтл + серия) с авто-обновлением из истории.
4. **P2**: Спойлер-теги в отзывах (`[spoiler]…[/spoiler]` с раскрытием по клику).
5. **P3**: PWA-install prompt + offline-страница избранного (SW уже умеет shell).
6. **P3**: Тёмный/светлый авто-переключатель по расписанию (закат/рассвет) поверх system.
7. **P3**: Глобальный поиск «всё сразу» (тайтлы + жанры + клубы + форум) в CommandPalette.
8. **P3**: Ежегодный отчёт «Итоги года» (как Spotify Wrapped) с шером в PNG.

## Оценка ёмкости стиля (сравнение визуала)

- **Shikimori**: утилитарный светлый/тёмный, плотные списки, минимум анимаций → мы выигрываем в motion/карточках.
- **AniLibria**: тёмный неон, крупные релизные карточки, акцент на озвучках → берём их EP-бейджи и группировку по дням (сделано).
- **AnimeGO**: максимально плотная сетка, «всё на экране» → не копируем: наша плотность уже сбалансирована дизайн-пасом.
- **MAL**: устаревший утилитаризм → только паттерн чартов.
- Вывод: наш вектор — «тёмный кинематографичный + воздух», добор: хабы франшиз/сезонов и hover-трейлеры.
