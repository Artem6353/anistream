**Дата:** 2026-11-20
**Этап:** B1-A (design exploration), ветка `design/aninova-3-b1-exploration-2026-11`, worktree `C:\Users\artem\anistream-design`
**Что это:** изолированный прототип трёх визуальных концепций на одинаковом наборе экранов. Ни один файл production-приложения не изменён, новые компоненты не интегрированы в действующий layout.

## 1. Бренд

**AniNova** — каталог и плеер аниме с отдельным доменом комиксов (только на русском). Тон: спокойный, точный, без «киберпанк-витрины».

### 1.1. Nova Pulse

Единственный обязательный фирменный визуальный элемент. Это точка + одно расходящееся кольцо.

| Параметр | Значение |
|---|---|
| Точка | круг 5–8 px, цвет `currentColor` |
| Кольцо | 1 px, `currentColor`, opacity 0.55 → 0 |
| Анимация | 3.4 s `ease-out`, scale 0.55 → 1.9, один раз в цикл |
| Условие | только при `prefers-reduced-motion: no-preference` |
| Где можно | логотип, статус «онгоинг / live», один активный раздел, прогресс чтения/просмотра |
| Где нельзя | кнопки, карточки целиком, фоны, декоративные пятна |
| Бюджет | не больше 3 «живых» пульсов на экран, остальные — статичные точки |

Реализация: `components/proto/Pulse.tsx` + `.pulse` / `.pulse--live` в `app/globals.css`. Размер задаётся `--pulse-size`. Уменьшение движения: `.pulse--live::after` получает `animation-duration: 0.001ms` (проверено автотестом, см. `audit.json → motion`).

### 1.2. Общая рамка, разный голос

Все три концепции используют один продуктовый словарь и одну информационную архитектуру, но разную типографику, плотность и композицию. Это позволяет сравнивать решения, а не наборы экранов.

3. Акцент — не больше 5–7% площади экрана. Никаких неоновых свечений и внешних glow, кроме одного технического случая: прогресс/статус.
4. Стеклянные карточки, blur-панели и «бесконечные» градиентные фоны запрещены во всех трёх концепциях (проверяется на ревью по классам `backdrop-filter`).

## 3. Типографика

Прототип использует системные стеки: это ноль сетевых запросов и честное измерение производительности. Финальный выбор шрифтов — решение владельца в B1-B (см. §12).

```css
/* A и C */
--font: ui-sans-serif, system-ui, 'Segoe UI Variable Text', 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;
/* B */
--serif: Georgia, 'Iowan Old Style', 'Palatino Linotype', 'Times New Roman', serif;
--sans: ui-sans-serif, system-ui, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;
```

### 3.1. Шкала

| Роль | A Minimal | B Editorial | C Cinematic |
|---|---|---|---|
| Hero H1 | `clamp(32px, 4.6vw, 50px)` / 1.04 / −0.035em / 600 | `clamp(30px, 5vw, 54px)` / 1.04 / −0.02em / 400 | `clamp(34px, 6vw, 82px)` / 0.94 / −0.04em / 700 uppercase |
| H1 страницы | `clamp(26px, 3.4vw, 34px)` | `clamp(32px, 5vw, 48px)` | `clamp(30px, 5vw, 58px)` uppercase |
| H2 секции | 12 px, uppercase, +0.1em | 24 px serif | 15 px, uppercase, +0.14em, 700 |
| H3 карточки | 13.5–14.5 px / 1.3 | 16–19 px serif | 13–14 px / 1.3 |
| Body | 14.5–15 px / 1.6 | 16.5–17 px / 1.66 serif | 15 px / 1.65 |
| Служебное | 10.5–12 px, +0.1em uppercase | 10.5 px, +0.14em uppercase | 9.5–11 px, +0.16…0.22em uppercase |
| Цифры | `font-variant-numeric: tabular-nums` | `oldstyle-nums` в читалке | tabular не нужен |

### 3.2. Правила

- Один H1 на страницу; заголовки не стилизуются через `div`.
- Максимальная длина строки: 66–68 ch для прозы (B), 52–62 ch для лидов, 46 ch для hero-лида A.
- `text-wrap: balance` только для H1 (A, B, C-hero).
- Uppercase — только для меток/рубрик и display-заголовков C; body никогда не бывает uppercase.
- Трекинг: отрицательный только у крупных кеглей (−0.02…−0.04em), положительный — у мелких uppercase (+0.1…0.22em).

## 5. Компоненты

Классы имеют префикс концепции: `.m-` (Minimal), `.e-` (Editorial), `.c-` (Cinematic). Общие интерактивные примитивы — без префикса, но со скоупом `[data-concept]`: `.auth-*`, `.rd-*`, `.vt`.

### 5.1. Навигация

| | A | B | C |
|---|---|---|---|
| Desktop | текст-навигация, активный пункт — подчёркивание 1 px акцентом | рубрики под мастохедом, активная — 2 px `--seal` | uppercase-навигация, активная — 2 px `--accent` |
| Мобильная | drawer: строки 19 px, hairline, кнопки входа внизу | меню-обложка: serif 26 px, номера разделов, крупные кнопки | фиксированная нижняя панель: 4 иконки + подписи, safe-area |
| Поиск | панель под шапкой, инпут 17 px, результаты строками | панель под мастохедом, serif-инпут 22 px, результаты с точечным лидером | полноэкранный оверлей под шапкой, инпут 20 px, результаты с миниатюрами |

### 5.3. Карточка / строка

- **A:** каталог — строки (46 px постер + текст + метаданные + рейтинг); карточка 2:3 используется только на главной и в «продолжить».
- **B:** индекс — строки с номером, названием, оригиналом и метаданными; обложки только в редакционных блоках.
- **C:** карточка 2:3 с бейджем рейтинга; в режиме списка превращается в строку 64–72 px с обложкой слева (тот же компонент, `data-view`).

Состояния карточки: `hover` (сдвиг/яркость/цвет заголовка — по концепции), `focus-visible` (2 px outline), `saved` (`aria-pressed="true"`, заливка иконки). Все карточки — ссылки целиком, без вложенных интерактивных зон.

### 5.4. Формы

- Метки всегда видимы (никаких placeholder-вместо-label).
- Ошибка: `aria-invalid="true"` + текст с `role="alert"` + рамка/подчёркивание цвета ошибки.
- Пароль: кнопка показа с `aria-pressed` и доступным именем.
- Регистрация: обязательное согласие, ошибка привязана к чекбоксу.
- Демо-статус: подпись «Supabase не подключён», отправка не выполняется; успешная валидация показывает `role="status"`.

Проверено: пустая отправка даёт 2–4 ошибки, корректные значения — статус «Проверка пройдена».

### 5.5. Плеер

- Разметка сцены: `aspect-ratio` (16:9 у A/C, 21:9 у B), постер, скрим, центральная кнопка Play.
- Контролы: play/pause, mute, таймлайн `<input type="range">`, время, качество, озвучка, fullscreen.
- Таймлайн имеет `aria-label` и `aria-valuetext`; состояние воспроизведения отражается в `aria-label`.
- Видеопоток не подключён: подпись «Демо-плеер» присутствует на всех трёх экранах. Production-плеер не изменялся.

## 6. Движение

| Событие | Длительность | Кривая | Где |
|---|---|---|---|
| Hover карточки | 160–400 ms | ease | A (яркость), C (scale 1.03) |
| Появление/смена страницы читалки | 160 ms | ease | прогресс-бар |
| Nova Pulse | 3.4 s, infinite | ease-out | только live-индикаторы |
| Прочее | без анимаций | — | — |

Правила:

1. Нет автопрокруток, каруселей с автоплеем, «дыхания» фонов.
2. Максимум одно бесконечное движение на экран — Nova Pulse, и только при разрешённом движении.
3. `prefers-reduced-motion: reduce` отключает все анимации и переходы глобально (`app/globals.css`), `scroll-behavior` становится `auto`.
4. Никаких анимаций, влияющих на layout (только `transform`/`opacity`/`filter`).

Проверка: `audit.json → motion` = `{ mediaMatches: true, pulseAnimation: "1e-06s", scrollBehavior: "auto" }`.

## 7. Темы

- Тема хранится в `localStorage` (`aninova-proto-theme`) и применяется инлайн-скриптом до первой отрисовки — без вспышки.
- По умолчанию: A — тёмная, B — светлая, C — тёмная; переключатель в каждой шапке и в панели прототипа.
- Тема не является «инверсией»: у B ночной выпуск меняет не только цвета, но и тон иллюстраций (opacity), у C светлая тема — «дневной сеанс», при этом сцена плеера остаётся тёмной.
- Обе темы обязательны для каждого экрана; проверка контраста выполняется для обеих (60 страниц × тема).

## 9. Доступность

Цель — WCAG 2.2 AA для прототипа.

| Проверка | Как | Результат |
|---|---|---|
| Контраст текста | расчёт WCAG-ratio по computed styles на 60 комбинациях (3 концепции × 2 темы × 10 экранов), с пропуском текста поверх изображений | **0 нарушений**, минимум **4.56:1** |

| Клавиатура: поиск | фокус на кнопке → Enter → фокус в поле → Esc | 3/3 концепции, outline 2 px |
| Клавиатура: читалка | ←/→ меняют страницу | 3/3, «1 / 4» → «2 / 4» |
| Клавиатура: вкладки | ←/→/Home/End | реализовано в `Tabs` |
| Reduced motion | эмуляция `prefers-reduced-motion: reduce` | анимация пульса 1e-06 s, scroll-behavior auto |
| Семантика | `header/main/nav/aside/footer`, один H1, `aria-current`, `aria-live` у счётчика страниц | вручную |
| Skip-link | первая ссылка на каждой странице | есть |
| Цели касания | иконки 44×44 на мобильном (A, C), 38–40 на десктопе | есть |
| Формы | видимые метки, `aria-invalid`, `role="alert"`, `role="status"` | есть |

Известные ограничения: hero-текст поверх изображений проверяется визуально (скрим рассчитан на контраст ≥4.5 к светлому тексту), автотест такие зоны пропускает; фокус-ловушки в мобильном меню нет — при открытом меню Tab уходит в контент под ним (зафиксировано в §Known issues респонсив-спеки).

## 12. Что не готово к production (решения для B1-B)

1. **Шрифты.** Сейчас системные стеки. Для финального продукта нужен один variable-шрифт (гротеск) и, если владелец выберет Editorial, один serif — self-hosted, subset `cyrillic+latin`, бюджет ≤120 KB woff2, `font-display: swap`.
2. **Данные.** Все тайтлы, рейтинги, эпизоды, главы и прогресс — mock. Подключение каталога и Supabase — отдельный этап, вне B1-A.
3. **Плеер.** Это макет сцены и контролов, не интеграция. Рабочий плеер не переписывался.
4. **Auth.** Демо-валидация без отправки; реальные flow (recovery, смена пароля, merge гостя) — B4.
5. **Комиксы.** Права, RU-only gate и реальные главы — B3. Метка «только RU» присутствует как продуктовое требование.
6. **Изображения.** Mock-арт не является постерами; в production — прокси `/img` и правила прав.
7. **ТВ.** 1920 проверен по сетке и кеглю; отдельный 10-foot UI (фокус-навигация пультом) — задача B6, не B1-A.
8. **Интеграция.** Ни один компонент не подключён к действующему приложению. Это сознательно: сначала выбор направления владельцем.
