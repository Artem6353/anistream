## 5. Найденные и исправленные ошибки

### 5.1. Ложные первоисточники: 85 рёбер с перевёрнутым направлением (критично)

AniList ставит `ADAPTATION` в обе стороны и не различает, кто оригинал. B1-C считал любой такой
комикс первоисточником — включая мангу, вышедшую **после** аниме. На реальных данных это 85 рёбер
(85 карточек на 85 аниме), например: «Плач девичьей группы» (2024) с мангами 2026 года,
«Детектив Конан: Квартал молчания» (2011) с мангой 2014/2021, G Gundam (1994) с мангой 2010–2014.

Исправление: направление определяется датами (`SOURCE_YEAR_TOLERANCE = 1` год), а не только
relationType. Комикс, начавшийся позже аниме более чем на год, получает роль `ADAPTATION`,
подпись «Комикс по аниме», не участвует в выборе основного первоисточника и не делает секцию
«Первоисточник». Обратное направление на странице комикса считается тем же правилом: аниме
подписано «Оригинальный сериал».

Итог: `SOURCE` 3711 → 3626, многоисточниковых аниме 146 → 118, «только связанные» 1285 → 1331.
Проверено тестами (4 unit) и инвариантом в отчёте: ни один `SOURCE`-комикс не начинается позже
аниме более чем на год (`sourcesAfterAnimeCount = 0`).

### 5.2. Все обложки кандидатов были битыми (2198 из 2198)

Shikimori отдаёт относительный путь (`/system/mangas/...`), скрипт сохранял его как есть.
Исправлено: нормализация в абсолютный URL + перегенерация файлов. Тот же проход перепроверил
привязку id для всех 2270 произведений (`myanimelist_id` из ответа сверяется с запрошенным MAL id:
расхождений 0).

### 5.3. «Кандидаты» без русского названия (28)

Ответы Shikimori с пустым `russian` попадали в слой кандидатов с пустым названием. Введён статус
`NO_RU_TITLE` — такие записи не считаются кандидатами: 2198 → 2170 кандидатов.

### 5.4. Пустые значения `license_name_ru` (3)

Пустая строка вместо «нет данных». Нормализовано в `null`; в скрипте исправлено на будущее.

### 5.5. Флейк e2e TV-теста

`aninova3-tv.spec.ts` «фокус заметен на тёмном фоне» падал примерно 1 раз из 10: `ArrowDown`
приходил раньше инициализации TV-навигатора. Тест теперь ждёт `data-tv="true"` (3 прогона подряд
и полный набор — зелёные). Это дефект теста, а не продукта.

### 5.6. Что ошибкой не является (проверено и оставлено)

- 60 совпадений оригинальных названий у разных AniList id — разные произведения с одинаковым
  названием; поиск по названию не используется, влияния нет.
- 540 произведений без MAL id и 52 ваншота без MAL id — источник их просто не имеет.
- 1 дубль MAL (G Gundam: 4 AniList-записи → один MAL 124776) — записи не сливаются автоматически,
  случай в очереди проверки; resolver уже не разрешает такие связи по MAL id.
- 2 отсутствующих в AniList id (2265, 2268) — данные источника, не наша ошибка.

## 7. Соблюдение правил публикации Comics

| Требование | Как проверено | Результат |
|---|---|---|
| В каталоге только подтверждённые RU-произведения | e2e: в каталоге 8 строк, все помечены «демо» | выполнено (реальных `APPROVED` — 0) |

| Первоисточник ≠ разрешение читать | `canOpenReader` требует права + главы со страницами | выполнено |
| Права не появляются из AniList/MAL/Shikimori | `rightsVerified` только из редакционной записи; тест на всех 4100 | выполнено |

Замечание: слаг маршрута для непроверенных произведений по-прежнему строится из оригинального

публикуемое название, но в B1-E стоит перейти на нейтральные слаги для непроверенных записей.

## 11. Ограничения и что дальше

1. **Даты — эвристика.** Направление определяется годом начала; при равном годе остаётся
   `SOURCE` (допуск 1 год). Это осознанно консервативно, но требует выборочной редакционной сверки —
   очередь содержит 85 случаев «комикс вышел после аниме».
2. **Промо-манги.** 13 многоисточниковых аниме имеют источник того же года без числа глав —
   вероятно, манга выпущена к аниме. Автоматически не переклассифицируются.
3. **Дубль MAL (G Gundam).** 4 AniList-записи на один MAL; слияние — редакционное решение.
4. **Слаги непроверенных произведений** построены из оригинального названия (см. §7).
5. **RU-метаданные:** 2170 кандидатов ждут редакционной сверки; 174 произведения без MAL id,
   67 с несовпадением названия, 5 не найдены, 28 без русского названия.
6. **Права и главы** по-прежнему отсутствуют у всех — читаемых произведений 0.
7. Снимок датированный: обновляется `npm run graph:b1c` (полный проход ~7 минут), аудит —
   `npm run graph:audit -- --fetch`.

Следующий этап (B1-E): редакционная сверка очереди (в первую очередь 30 многоисточниковых случаев),
массовое подтверждение RU-названий по 2170 кандидатам, нейтральные слаги, перенос модели в БД.
