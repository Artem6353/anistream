# B1-C: русский язык и правила публикации

Код: `lib/aninova3/comics/publication.ts`, `lib/aninova3/comics/source-data.ts`.

## 1. Главное правило

Публичный каталог Comics — только произведения с **русским названием**, проверенными **русскими
метаданными**, **реальными русскими главами** и **подтверждёнными правами**. Читалка открывает
исключительно русскоязычные главы.

```ts
isPubliclyReadable =
  publicationStatus === 'APPROVED' &&
  russianTitleVerified &&
  russianMetadataVerified &&
  rightsVerified &&
  publicRuChapters.length > 0;
```

Дополнительно, отдельной проверкой:

```ts
canOpenReader = isPubliclyReadable && hasReaderSource(comic); // есть хотя бы одна RU-глава с реальными страницами
```

Разделение нужно, чтобы не появлялась ссылка в 404: «права подтверждены» и «есть что показать» —
разные вещи.

## 2. Состояния публикации

| Статус | Значение | Видно в preview |
|---|---|---|
| `DRAFT` | черновик | карточка честно закрыта |
| `PENDING_VERIFICATION` | ожидает проверки | карточка честно закрыта |
| `APPROVED` | публикация разрешена | читается при остальных флагах |
| `REJECTED` | публикация запрещена | карточка без ссылок на произведение |
| `EXPIRED` | разрешение истекло | карточка без ссылок на произведение |

Флаги (`ComicPublication`): `russianTitleVerified`, `russianMetadataVerified`, `rightsVerified`,
плюс `verificationBasis` (`anilist-relation|editorial|fixture`) и `verifiedAt` для аудита.

## 3. Главы

- Принимается только `language === 'ru'` **и** `number > 0` **и** `pages > 0`.
- `en`, `ja`, `ko`, `zh`, `other` никогда не подставляются как fallback.
- Отсутствующие главы не генерируются: `chapters: []` = «читать нечего».
- Страницы читалки берутся только из `chapter.pageImages` (реальные файлы). Пусто → кнопки чтения нет.
- Число «известно глав» (`totalChaptersKnown`) — справочная цифра из источника, она **не** выдаётся за доступное чтение (в карточке рядом прямо написано «Русских глав нет»).

## 4. Права отдельно от перевода

1. Наличие русского текста, скана или доступной страницы в интернете **не** является разрешением на перепубликацию.
2. `rightsVerified: true` ставится только при подтверждённом основании; в публичных полях нет названий договоров, лицензий и внутренних документов.
3. Демо-контент B1-B никогда не считается реальным: `isDemo` → `publicationIssues` содержит `demo`, `isPubliclyReadable` = `false`.
4. Автоматический импорт чужих сканов/переводов в публичную читалку запрещён: в B1-C такого импорта нет вообще.

## 5. Когда первоисточник есть, но читать нельзя

Разрешённое информационное состояние (используется для Naruto):

- карточка показывается: обложка, название, вид, автор (если проверен), год, статус;
- нет активной кнопки чтения;
- нет фиктивных глав;
- нет английского издания «вместо»;
- нет фальшивого статуса «доступно»;
- текст: «Первоисточник установлен, публикация пока недоступна: ожидает проверки · права не подтверждены · нет доступных русских глав».

Отдельное состояние — «права подтверждены, но страницы не подключены»: так и написано, без CTA.

## 6. Что видит пользователь и что остаётся внутренним

| Публично | Только внутренне (отчёт/аудит) |
|---|---|
| «Права не подтверждены» | какие именно документы и когда проверялись |
| «Нет доступных русских глав» | сколько глав существует в источнике и почему не подключены |
| «Русское название не подтверждено» | откуда взято название-кандидат |
| тип связи и её основание («по идентификатору AniList») | сырой `relationType`, дата наблюдения, id ребра |

## 7. Матрица публикации (покрыта тестами)

| Случай | Статус | Права | RU-название | RU-главы со страницами | Итог |
|---|---|---|---|---|---|
| Готово к чтению | APPROVED | да | да | да | читается, CTA есть |
| Права есть, страниц нет | APPROVED | да | да | нет страниц | CTA нет, честный текст |
| Нет прав | PENDING | нет | да | да | CTA нет |
| Только иностранные главы | APPROVED | да | да | нет RU | CTA нет, `no_ru_chapters` |
| Непроверенное название | DRAFT | нет | нет | нет | CTA нет, `title_unverified` |
| Истекшее разрешение | EXPIRED | да | да | да | CTA нет, `expired` |
| Демо B1-B | — | — | — | демо-страницы | помечено «демо», публично не читается |

Все строки матрицы закреплены в `tests/aninova3-comics-publication.test.ts` и `tests/aninova3-comics-resolver.test.ts`.

## 8. Пометка демо в каталоге Comics

- 8 вымышленных произведений B1-B остаются с явной маркировкой «демо» в каталоге и на странице произведения;
- они не участвуют в связях: `isDemo` отбрасывается при разрешении первоисточника;
- публичный каталог не смешивает демо и реальные проверенные произведения: реальные появятся только после `APPROVED`.

## 9. Что нужно для расширения публикации

1. Редакционная запись на каждое произведение в `source-data.ts` (название, автор, описание, флаги).
2. Подтверждение прав с датой и сроком (`rightsVerified`, `verifiedAt`).
3. Реальные русские главы с посчитанными страницами (`chapters[].pageImages`).
4. Проверка, что читалка получает файлы законно (в B1-C файлов глав не добавлено ни одного).
